# ESP32 Firmware Workflow

## When to Use
- Board: `esp32:esp32:esp32` (Arduino CLI)
- Partition scheme: `huge_app` (app0 = 0x300000 = 3,145,728 B)
- Build property: `--build-property "build.extra_flags=-I<repo>/src"` for LVGL include paths when headers live in `src/`
- Project: ESP32 Smart Gauge `SUN_DIAG_GAUGE_v1_1_1_BETA17_WAVE110I_ECUID_UNLOCK`

## Workflow

### Step 1 — Confirm build target and partition
```bash
arduino-cli version
arduino-cli core list
# Verify huge_app partition: app0 = 0x300000 = 3,145,728 B
```
Default `min_spiffs` fails: sketch exceeds 1,310,720 B app limit.

### Step 2 — Compile with partition + include path
```bash
arduino-cli compile --fqbn esp32:esp32:esp32 \
  --board-options "PartitionScheme=huge_app" \
  --build-property "build.extra_flags=-I<repo>/src" \
  --build-path <build_dir> <project_root>
```

### Step 3 — Verify exit code and memory metrics
- **EXIT=0** → PASS
- Flash: 1,801,287 B (57%) of 3,145,728 B (huge_app)
- RAM: 59,064 B (18%) of 327,680 B

### Step 4 — Update build script for out-of-the-box success
`tools/COMPILE_AND_UPLOAD.sh`:
```bash
PARTITION="huge_app"
FQBN="esp32:esp32:esp32"
arduino-cli compile --fqbn "$FQBN" \
  --board-options "PartitionScheme=${PARTITION}" \
  --build-property "build.extra_flags=-I${PROJECT_DIR}/src" \
  --build-path "$SAFE_BUILD" "$SAFE_PROJECT"
```
Use `PROJECT_DIR` (resolved to repo root) rather than `PWD`.

### Step 5 — Documentation standards
- Source of truth: `src/00_SG_Config.h` — `#define SG_FIRMWARE_VERSION`
- All docs cite/reproduce this value; no independent version strings
- Build/label variables derive from this macro

### Step 6 — Documentation files created

### Step 7 — Commit and verify
```bash
git add -A
git commit -m "chore: finalize step 2 restructure, include flags, and execution report"
git status --short  # empty = clean
```

## Pitfalls
1. **`arduino-cli compile` without partition flag uses `min_spiffs`** — always pass `--board-options PartitionScheme=huge_app`.
2. **Modular `src/` layout breaks LVGL include chain** — `lv_conf_internal.h` includes `lv_conf.h` which lives in `src/` → `fatal error: lv_conf.h`. Fix with `--build-property "build.extra_flags=-I<repo>/src"`.
3. **Do not embed partition in FQBN** — use `--board-options PartitionScheme=huge_app`.
4. **Always verify build artifacts do not leak** — `git status --porcelain` must show no untracked `.pio/`, `build/`, or `*.log` files.

## Team delegation pattern
- **Lead-Architect**: supervise commit, define documentation standards, approve reports
- **Core-Developer**: file migration, script updates, git commit
- **QA-Debugger**: build verification, documentation creation, baseline recording

## Report format
- `--title: DOCS/STEP<N>_EXECUTION_REPORT.md`
- Sections: commands, outputs, memory metrics, verdict table, bottom-line summary
- Mark step COMPLETE only when: exit 0, git clean, report exported
